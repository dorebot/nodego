# SETPS TO RUN THE CODE

1. `git clone https://github.com/dorebot/nodego.git`
2. `cd nodego`
3. `pip install -r requirements.txt`
4. Add Proxy in the `proxy.txt` !! Formate as # HTTP://username:pass@ip:port.
5. Add Email pass in `accounts.txt` file and username in `username.txt` file.
6. Add Your Referal code in the `reg.py` line 25 add as many codes you wanted !! also replace your 2captcha Api keys in line number 65.
7. TO reg run `python reg.py`.
8. TO Daily claim run `python dailyclaim.py`.
9. TO complete all tasks run `python tasks.py`
10. To Mine run `python mine.py`
